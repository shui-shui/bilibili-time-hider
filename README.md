# B站进度时间隐藏

隐藏 B 站播放器的进度时间，帮助沉浸式学习，减少查看进度带来的焦虑。
# 🙈 BiliFlowHide

&gt; 一个帮你挡住 B 站进度时间的浏览器插件——看不见进度，才看得进内容。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 为什么做这个

我是一个很难进入心流的人：好动、坐不住，内心抗拒"看视频学习"这件事。

但矛盾的是，有些东西看视频就是比读文字理解得快、记得牢。

所以每次学习都像一场拉锯战——

**视频才放 3 分钟，我已经看了 8 次进度条。**
`11:30 / 11:33` 这几个数字像有魔力一样，我根本管不住眼睛。
注意力全在"还有多久看完"上，至于视频里讲了什么？根本没进脑子。

**我在意的是进度，不是产出。**

后来我想明白了：
只要那个时间数字还在屏幕上，我的注意力就永远被它勾着走。

那为什么不把它藏起来呢？

于是就做了这个插件。


## 安装

### 手动加载（开发中）

1. 克隆本仓库：`git clone https://github.com/你的用户名/BiliFlowHide.git`
2. 打开 Chrome，访问 `chrome://extensions/`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本仓库文件夹
5. 打开任意 B 站视频，进度时间应该已经消失了 ✅

&gt; **注意**：B 站前端改版频繁，如果发现某处时间没被隐藏，欢迎提 Issue 或 PR。

## 使用

- 点击浏览器工具栏的插件图标，可以开关各项功能
- 默认快捷键 `Alt + T` 临时查看进度时间（可在浏览器扩展设置中修改）

## 它不适合谁

- 看学习视频需要严格卡时间的人（比如考前刷课做精确规划）
- 其实你可以用「临时查看」和「模糊化显示」解决，但诚实一点总没错

## 为什么"模糊时间"比"完全隐藏"更好

试过的朋友可能会发现：完全没时间提示时，你会在心里更焦虑地盘算"到底还有多久"。
所以插件里保留了**模糊化选项**：告诉你"还剩大约 5 分钟"，但不告诉你"还剩 4 分 47 秒"。

够你安排学习节奏，不够你每分钟看 8 次。

这是我对抗分心这么多年悟出的一个道理：
**根治注意力问题，靠的不是更强的意志力，而是更聪明的环境设计。**

## 技术栈

- Manifest V3
- Content Script + CSS 注入
- MutationObserver 应对 B 站 SPA 动态加载

## 功能
- **临时查看**：按 `Alt+T` 临时显示进度时间，约 4 秒后自动恢复隐藏
- **开关**：点击浏览器工具栏图标一键启用/禁用，设置保存在本地

## 安装

适用于 Chrome / Edge 等 Chromium 内核浏览器。

1. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本仓库文件夹

## 使用

- 点击工具栏图标，在弹出的面板中开关各项功能
- 快捷键 `Alt+T` 临时查看时间（可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 修改）

## 技术说明

- Manifest V3 + content script
- 纯 CSS `display: none` 为主，性能好、抗闪烁；配合 `MutationObserver` + 多组备选选择器兜底，兼容 B 站 SPA 路由切换
- 仅对 `bilibili.com` 和 `b23.tv` 生效
- 所有设置保存在本地 `chrome.storage.local`，不上传任何数据
