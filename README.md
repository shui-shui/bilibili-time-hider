# 🙈 BiliFlowHide

> 一个帮你挡住 B 站进度时间的浏览器插件——看不见进度，才看得进内容。

## 为什么做这个

我是一个很难进入心流的人：好动、坐不住，内心抗拒"看视频学习"这件事。

但矛盾的是，有些东西看视频就是比读文字理解得快、记得牢。

所以每次学习都像一场拉锯战——

**视频才放 3 分钟，我已经看了 8 次进度条。**
`11:30 / 11:33` 这几个数字像有魔力一样，我根本管不住眼睛。
注意力全在"还有多久看完"上，至于视频里讲了什么？根本没进脑子。

**我在意的是进度，不是产出。**

后来我想明白了：
只要那个时间数字还在屏幕上，我的注意力就永远被它勾着走。

那为什么不把它藏起来呢？

于是就做了这个插件。

## 功能

- **隐藏时间**：隐藏播放器控制栏的「当前时间 / 总时长」（含全屏），以及悬停进度条时出现的时间气泡
- **临时查看**：按 `Alt + T` 临时显示进度时间，几秒后自动恢复隐藏
- **开关**：点击浏览器工具栏图标一键启用/禁用

## 安装

1. 克隆本仓库：`git clone https://github.com/shui-shui/bilibili-time-hider.git`
2. 打开 Chrome / Edge 的扩展管理页（`chrome://extensions` 或 `edge://extensions`）
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本仓库文件夹
5. 打开任意 B 站视频，进度时间应该已经消失了 ✅

> **注意**：B 站前端改版频繁，如果发现某处时间没被隐藏，欢迎提 Issue 或 PR。

## 使用

- 点击浏览器工具栏的插件图标，可以开关功能
- 默认快捷键 `Alt + T` 临时查看进度时间（可在浏览器扩展设置中修改）

## 它不适合谁

- 看学习视频需要严格卡时间的人（比如考前刷课做精确规划）

## 技术栈

- Manifest V3
- Content Script + CSS 注入
- MutationObserver 应对 B 站 SPA 动态加载
