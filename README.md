# B站进度时间隐藏

隐藏 B 站播放器的进度时间，帮助沉浸式学习，减少查看进度带来的焦虑。

## 功能

- **隐藏时间**：隐藏播放器控制栏的「当前时间 / 总时长」（含全屏），以及悬停进度条时出现的时间气泡
- **学习模式**（可选）：额外隐藏选集/分 P 列表、右侧推荐流封面上的视频时长角标
- **隐藏进度条**（可选）：连「看了多少」也隐藏
- **伪装时间**（可选）：把具体时间替换为模糊文案，如「已看一半」「还剩约 5 分钟」
- **临时查看**：按 `Alt+T` 临时显示进度时间，约 4 秒后自动恢复隐藏
- **开关**：点击浏览器工具栏图标一键启用/禁用，设置保存在本地

## 安装

适用于 Chrome / Edge 等 Chromium 内核浏览器。

1. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本仓库文件夹

## 使用

- 点击工具栏图标，在弹出的面板中开关各项功能
- 快捷键 `Alt+T` 临时查看时间（可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 修改）

## 技术说明

- Manifest V3 + content script
- 纯 CSS `display: none` 为主，性能好、抗闪烁；配合 `MutationObserver` + 多组备选选择器兜底，兼容 B 站 SPA 路由切换
- 仅对 `bilibili.com` 和 `b23.tv` 生效
- 所有设置保存在本地 `chrome.storage.local`，不上传任何数据
